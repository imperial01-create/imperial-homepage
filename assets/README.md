# assets

검색·AI 답변엔진과 카카오톡/네이버 공유 카드에 쓰이는 이미지를 두는 곳입니다.

여기에 파일을 넣고 `npm run build` 를 실행하면 `og:image`, `twitter:image`,
JSON-LD `logo`, 파비콘 태그가 **자동으로 생성**됩니다.
파일이 없으면 해당 태그는 아예 생성되지 않으므로 깨진 링크가 나가지 않습니다.
이미지 크기(width/height)도 빌드 시 파일에서 직접 읽으므로 따로 적을 필요가 없습니다.

| 파일명 | 용도 | 권장 규격 | 필수 |
|---|---|---|---|
| `logo.jpg` | JSON-LD 로고, og:image 대체 | 정사각형, 512px 이상 | ✅ |
| `og.jpg` | 카카오톡·네이버·SNS 공유 카드 | **1200 × 630** (가로형) | 권장 |
| `favicon.ico` | 브라우저 탭 아이콘, 구글 검색 결과 파비콘 | 32×32 또는 48×48 | 권장 |
| `apple-touch-icon.png` | iOS 홈 화면 아이콘 | 180×180 | 선택 |

`og.jpg` 가 없으면 `logo.jpg` 가 공유 카드 이미지로 대신 쓰입니다.
다만 공유 카드는 가로 1200×630 비율로 잘리므로, 정사각 로고만 있으면 양옆이 잘립니다.
가로형 `og.jpg` 를 따로 만들어 두는 편이 좋고, 그 안에 **학원명 · 주소 · 전화번호**가
읽히도록 넣으면 AI 답변에 썸네일로 노출될 때 정보 전달력이 올라갑니다.

경로를 바꾸고 싶으면 `src/site.config.js` 의 `logo` / `ogImage` / `favicon` /
`appleTouchIcon` 값을 수정하세요.
